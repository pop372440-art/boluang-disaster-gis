# แบบจำลองความเสี่ยงฝนและดินถล่ม

## ขอบเขต

ระบบนี้เป็นเครื่องมือสนับสนุนการตัดสินใจ ไม่ใช่คำเตือนภัยอย่างเป็นทางการ ดัชนีรายหมู่บ้านใช้ฝนจากแบบจำลอง Open-Meteo; ภาพเรดาร์ RainViewer ใช้สำหรับการสังเกตและ nowcast บนแผนที่ แต่ยังไม่ถูกป้อนเข้าดัชนี

## การคำนวณ

1. สร้างจุดตัวอย่างภายใน polygon หมู่บ้าน 5–12 จุด โดยเพิ่มจำนวนตามพื้นที่ประมาณ 1 จุดต่อ 12 ตร.กม.
2. เลือกสามชั่วโมงแรกตั้งแต่ชั่วโมงปัจจุบันหรือชั่วโมงถัดไป รวมเป็นฝน 3 ชั่วโมง
3. ใช้ค่าสูงสุดของจุดที่ข้อมูลครบเป็นตัวขับเชิงปฏิบัติการ พร้อมแสดง mean, max และ p90 เพื่อวินิจฉัย
4. คำนวณ `risk = rain3h × soilFactor(API7) × terrainFactor` และจัดระดับตาม `threshold-config.ts`
5. ถ้าข้อมูลไม่ครบ เก่า หรือหมดอายุ จะไม่อนุญาตให้สร้าง alert

ภาพรวมตำบลใช้ค่าเฉลี่ยถ่วงน้ำหนักด้วยพื้นที่ polygon และ “สัดส่วนพื้นที่มีฝน” คือพื้นที่ของหมู่บ้านที่ฝนมากกว่า 1 มม. หารด้วยพื้นที่ที่มีข้อมูล ไม่ใช่สัดส่วนจำนวนหมู่บ้าน

## ข้อจำกัด

- polygon หมู่บ้านไม่ใช่กริดพยากรณ์ จึงมีความละเอียดเท่าที่แบบจำลองต้นทางรองรับ
- GeoJSON ไม่มี slope/DEM รายหมู่บ้าน จึงลดระดับความเชื่อมั่นด้านภูมิประเทศ
- API7 เป็นฝนจากแบบจำลองย้อนหลัง ไม่ใช่ความชื้นดินที่วัดจริง
- เกณฑ์ปัจจุบันเป็นค่าเริ่มต้น ต้องสอบเทียบกับเครื่องวัดฝนและเหตุการณ์จริงก่อนใช้งานเชิงประกาศ
