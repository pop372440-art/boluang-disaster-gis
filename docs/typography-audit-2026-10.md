# ปรับตัวอักษรเพื่อให้อ่านง่าย

วันที่ 15 ตุลาคม 2569 · ต่อจาก UX/UI audit และ main `85efb445`

## รายการที่ปรับ

| ส่วน | ก่อน | หลัง |
| --- | --- | --- |
| เมนูหลัก / ปุ่มหัวเว็บ | 12px | 14px |
| ชื่อ Layer | 13px | 16px |
| ปุ่มชุดชั้นข้อมูล | 11px | 14px |
| แหล่งข้อมูล / พิกัด / ข้อจำกัด | 10–12px | อย่างน้อย 14px |
| เนื้อหาหลัก / ช่องกรอก / ตัวเลือก | 13–14px ในหลายจุด | 16px |
| หัวข้อแผง GIS | 14–16px | 20px |

ใช้ scale เดียวกันกับหน้าศูนย์สถานการณ์ อากาศ น้ำ สิ่งแวดล้อม ผู้บริหาร สถิติ และข้อมูลเปิด รวมถึงส่วนติดต่อผู้ช่วย AI ข้อความ annotation ภายในสัญลักษณ์แผนที่ Leaflet ขนาดคงที่ยังคงขนาดเดิมเพื่อไม่ให้ล้น icon; ไม่ได้อ้างว่าตัวอักษรทุก glyph ของแผนที่มีขนาด 14px

ระยะบรรทัดเนื้อหา/ข้อมูลรอง 1.7 และปุ่ม/ลิงก์ 1.6 ใช้ rem ใน CSS ร่วม คงตัวอักษรเข้ม กรอบสีอ่อน และไอคอนเส้นแบบเดิม

## พื้นที่รองรับ

- แผงขวา 400px จาก 360px; แผงซ้าย 380px จาก 350px บน desktop
- ขยับระยะซ่อนแผง ตำแหน่งปุ่มแผนที่ และผู้ช่วยให้สัมพันธ์กับความกว้างใหม่
- แถบเมนูสูง 56px มีที่สำหรับตัวอักษรใหญ่ขึ้น และแผง desktop เริ่มใต้แถบที่ 144px
- บนมือถือ ปุ่มชุดข้อมูลเรียงสองคอลัมน์และปุ่มสุดท้ายเต็มแถว จอแคบกว่า 360px จัดลิงก์รายละเอียดพื้นที่เป็นแถวเดียว
- ช่องข้อมูลใช้ตัวอักษร 16px ปุ่มยังมีพื้นที่แตะอย่างน้อย 44px และแผงเลื่อนได้

## ขอบเขต

เปลี่ยนเฉพาะ class/CSS และการจัดวาง ไม่เปลี่ยนข้อความข้อมูลจาก upstream, API, lib, geometry, ค่าคำนวณ, เกณฑ์ภัย, freshness, รอบ refresh, schema, permission, dependencies หรือ configuration

## การตรวจ

- วัด computed styles บน browser: เมนู 14px, ชื่อ Layer 16px/line-height 27.2px, แหล่งข้อมูล 14px/line-height 23.8px
- ตรวจ desktop 1280×720, mobile 390×844 และ 320×720; ความกว้างเอกสารไม่ล้น viewport และปุ่มปิดแผงเข้าถึงได้
- ตรวจพื้นที่ 640×360 สำหรับ reflow ขณะมีพื้นที่แสดงผลจำกัด แผงเลื่อนได้ ไม่ลดขนาดตัวอักษรกลับเพื่อบีบข้อมูล
- ไม่ใช้การทดสอบ viewport แทนคำรับรอง WCAG: shortcut zoom ของเบราว์เซอร์ทดสอบไม่เปลี่ยนระดับ zoom จึงยังไม่ได้รับรองผล actual browser zoom 200% ควรตรวจซ้ำใน Chrome/Safari ของอุปกรณ์จริง
- ตรวจการเลือกหมู่บ้านและลิงก์รายละเอียด โดยคงพิกัดและชื่อพื้นที่เดิม
- ตรวจ TypeScript และ production build พร้อม CI ก่อนเผยแพร่; ไม่มี unit test ใหม่สำหรับการเปลี่ยน class/CSS ที่ย้อนกลับได้

ขอบเขตนี้เป็นการปรับความอ่านง่าย ไม่ใช่การรับรอง accessibility ทั้งระบบหรือความแม่นยำของข้อมูลภัยพิบัติ
