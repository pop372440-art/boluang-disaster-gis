# GIS data dictionary และ QA

## ขอบเขตหมู่บ้าน

ฟิลด์มาตรฐานหลัง normalize: `village_id`, `moo`, `name_th`, `__idx` โดย `village_id` เป็นรหัสคงที่ `moo-1` ถึง `moo-13`; ห้ามอ้าง array index เป็นเลขหมู่

## ความไวต่อดินถล่ม

| ฟิลด์ | ค่า | ความหมาย/สี |
|---|---|---|
| `class` | 1 | สูง / แดง |
| `class` | 2 | ปานกลาง / ส้ม |
| `ls_desth` | สูง, ปานกลาง | คำอธิบายภาษาไทย ใช้ยืนยัน class |

## QA ก่อนเผยแพร่ชุดข้อมูลใหม่

- CRS ต้องเป็น WGS84/EPSG:4326 หรือแปลงก่อน commit
- ring ต้องปิด, geometry ต้องเป็น Polygon/MultiPolygon และไม่มีพิกัดนอกช่วง
- ตรวจ self-intersection, ช่องว่าง/พื้นที่ซ้อนของหมู่บ้าน และผลรวมพื้นที่เทียบขอบเขตตำบล
- บันทึกหน่วยงานเจ้าของข้อมูล, วันที่สำรวจ/ปรับปรุง, license, scale/resolution และขั้นตอนแปลง
- ห้ามแสดงความแม่นยำระดับอาคารเมื่อข้อมูลเป็นระดับหมู่บ้าน
